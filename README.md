## Featured projects

### 🔐 Privacy-Preserving Federated Swarm Intelligence *(private repo, walkthrough on request)*
A document assistant that keeps private data private, plus a shared model that learns from volunteers without pooling their data.
- **DocRAG:** FastAPI, SQLite FTS5, ChromaDB and Ollama, with host / sub-host / user roles and every query isolated by group.
- **Kin Agent:** Electron + React desktop client that trains a Qwen2.5-0.5B LoRA adapter locally with Hugging Face and Flower.
- **Privacy:** SecAgg+, update clipping, central differential privacy and an RDP privacy ledger that blocks over-budget runs.
- **Status:** working prototype. The federated training pipeline has not been run end to end.

`Python` `FastAPI` `Flower` `PyTorch` `LoRA` `Electron` `React`
